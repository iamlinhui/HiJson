# HiJson

[English](./README.en.md) | 简体中文

一款基于 [Wails](https://wails.io/) 构建的轻量级 JSON 工具桌面应用，支持 JSON 格式化、压缩、过滤、深度解析、智能展开嵌套字符串等常用操作，适合日常排查接口返回、调试多层转义数据。

## 功能特性

### JSON 处理
- **JSON 格式化** — 保持键顺序的缩进格式化
- **排序格式化** — 按键名排序后格式化输出
- **JSON 压缩** — 移除空白字符，生成紧凑 JSON
- **过滤空值** — 移除 `null`、空字符串、空对象/数组（保持键顺序）
- **深度解析** — 自动展开 JSON 字符串值里嵌套的 JSON
- **智能展开** — 容错展开字符串里套着的字符串化 JSON（即使内层引号转义层数不对，也能按括号配平逐层剥开，常见于真实接口数据）

### 文本清洗（编辑菜单）
- **去转义** — 整段为多层转义字符串时逐层剥引号
- **清除 `\n` / 清除 `\`** — 去换行、去反斜杠
- **清空 / 粘帖** — 一键清空、粘贴并格式化

### 浏览与查找
- **树形视图** — 可折叠的 JSON 树，键名/键值着色
- **节点表格** — 选中节点展示键值表格
- **文本查找 / 节点查找** — 两种查找模式，支持上一个/下一个跳转
- **右键菜单** — 复制键名、键值、键名:键值、路径、节点内容（含格式化）

### 其他
- **多标签页** — 同时打开多段 JSON，互不干扰
- **文件拖拽打开** — 支持将 JSON 文件拖放到应用图标或窗口打开
- **文件读写** — 通过系统对话框打开和保存 JSON 文件
- **国际化** — 内置简体中文 / English 双语，工具栏一键切换，记住偏好
- **明暗主题** — 暗色 / 亮色主题切换，记住偏好
- **快捷键** — 常用操作均绑定快捷键（见下表）

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+N` | 新标签 |
| `Ctrl+F` | 格式化 |
| `Ctrl+G` | 排序格式化 |
| `Ctrl+H` | 压缩 |
| `Ctrl+B` | 过滤空值 |
| `Ctrl+E` | 深度解析 |
| `Ctrl+D` | 清空 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存文件 |
| `Esc` | 关闭查找栏 / 菜单 |

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Go 1.24 |
| 桌面框架 | Wails v2.12 |
| 前端 | HTML / JS（嵌入式，无构建步骤） |

## 快速开始

### 前置条件

- [Go](https://go.dev/) ≥ 1.24
- [Wails CLI](https://wails.io/docs/gettingstarted/installation) v2

### 开发模式

```bash
wails dev
```

### 构建

```bash
wails build
```

构建产物位于 `build/bin/` 目录。

## 项目结构

```
├── main.go                  # 应用入口
├── app.go                   # 后端 JSON 处理逻辑（含容错解析器）
├── app_test.go              # 后端单元测试
├── wails.json               # Wails 项目配置
├── frontend/
│   ├── dist/
│   │   └── index.html       # 嵌入式前端（单文件，含全部 UI 与 i18n 字典）
│   └── wailsjs/             # Wails 自动生成的前端绑定
└── build/
    ├── bin/                 # 可执行文件输出目录
    └── windows/            # Windows 平台资源（图标、清单等）
```
